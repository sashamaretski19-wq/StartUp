# Growth & Unit-Economics Audit для consumer AI

Лендинг консалтинговой услуги: аудит связки CAC → удержание → LTV для consumer AI
компаний, с переменной стоимостью инференса внутри модели.

Идея выросла из разбора YC Requests for Startups Fall 2026.

## Как смотреть

Открыть `index.html` в браузере. Сборки нет, зависимостей нет — чистые HTML/CSS/JS,
всё в одном файле на страницу.

Все страницы:

- подтягивают системную тему (светлую/тёмную) до первой отрисовки, кнопка в шапке
  переключает вручную и запоминает выбор в `localStorage`;
- адаптивны от 375px;
- считают всё на клиенте: ни сервера, ни внешних библиотек, ни отправки данных.

Лендинги содержат упрощённый калькулятор сходимости, демо-страницы — расчёт из
двенадцати полей, который собирает три страницы мини-дека: условие сходимости,
список допущений и порядок рычагов. Состояние расчёта пишется в адрес страницы,
поэтому ссылкой на конкретный расчёт можно поделиться.

## Как перегенерировать OG-картинки

Открыть `og-source.html` (или `og-source-en.html`), снять скриншот вьюпорта 1200×630
и положить в `images/og.png` (`images/og-en.png`).

## Что не входит в репозиторий

Внутренние рабочие материалы (аналитика, из которой выросла идея) лежат локально
и закрыты через `.gitignore` — публиковать их незачем.
